# Playbook — A Walk Around the Block (the show)

**Purpose:** every episode looks and feels the same, so people can count on it.
Johnny films; Mr Rogers assembles. Established 2026-08-25, after Episode №1.

## The handoff (Johnny's part — the whole part)
1. Film the take. Phone at eye level, window light or open shade, lav mic on.
   Use braveplumhealing.com/prompter.html if a script is wanted.
2. Drop the raw file on the **Desktop** named like `WATB-raw-<topic>.mp4`
   (or just tell Mr Rogers where it landed).
3. Say the word. That's it.

## The assembly (Mr Rogers' part, in Johnny's Chrome — Descript web)
1. In Descript drive: right-click **"TEMPLATE — A Walk Around the Block"** →
   Duplicate project → rename to `<Title> — A Walk Around the Block №<N>`.
   NEVER edit the TEMPLATE project itself.
2. Upload the raw file from Desktop into the new project; let it transcribe.
3. Replace the old episode's footage with the new take; keep the layouts.
4. Build the episode to the show grammar (below), reading the transcript for beats.
5. Review pass: full transcript read + frame checks + report to Johnny.
6. Johnny previews start-to-finish, then clicks **Export** (1080p) and
   **Share → update link**. Publishing anywhere is always Johnny's tap.

## The show grammar (what makes it "the show")
- **Format:** portrait 9:16 (1080×1920), ~3–5 min.
- **Cold open:** black title card, white serif — episode title. No logos, no intro reel.
- **Scene cards** at each teaching beat (4–6 per episode), a few words each,
  white serif on black (e.g. "Running on Empty" · "Two Flaggers, Two Energies" ·
  "React or respond? That's the choice.").
- **Quote scene** near the close: the episode's doctrine line as a card
  ("Triggers are the greatest teacher —if we pause and respond.").
- **End card (always identical, lives in the template):** black, EB Garamond 104,
  three centered lines: `Johnny Graf / Brave Plum Healing / braveplumhealing.com`, 5s.
- **Type:** EB Garamond (matches the template's serif cards). Never template
  default fonts/colors — if a layout arrives yellow-on-purple, it's broken; fix or delete.
- **Captions:** on, white, bottom-centered.
- **Music:** soft instrumental bed, low (№1 used "Letting Go (Instrumental)").
- **Sign-off stays in the footage:** "…thanks for being a beautiful human, and we'll
  see you later the next time we go for a walk around the block."
- **Naming:** project = `<Title> — A Walk Around the Block №<N>`; never IMG_xxxx.
- **Thumbnail:** outreach/videos/thumbnails/thumbnail-template.html (B&W portrait +
  plum panel), same kicker style every episode.
- **Description block:** one-line hook + "from Johnny Graf of Brave Plum Healing.
  Team building, workshops & retreats: braveplumhealing.com" (+ mini-lesson link
  when the episode has one, $2.28).

## Lessons already paid for
- Descript's AI edit ("Underlord") restyles every run — WILDLY inconsistent.
  Consistency comes from the duplicated TEMPLATE, never from re-generating.
- A broken template layout can bury finished scenes (Episode №1's finale sat under
  an oversized quote headline). When a scene looks wrong, check for an oversized
  layer on top before assuming the content is missing.
- Mr Rogers' keyboard input in the Descript editor must land in a focused text box;
  stray keys become editor shortcuts (splits scenes, changes playback speed).
  Verify focus with a screenshot before typing; storyboard view is the truth for
  scene count.
