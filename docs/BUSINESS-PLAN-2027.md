## Part 2 — The Eight Accomplishments, and the path to each

### 1. Brave Plum Healing established as a brand
**Today:** the site is live, designed, and true (real prices, real story, no invented
anything); the blossom mark is settled; the voice is defined (calm · valued · delight ·
trust).
**The path:** brand = repetition of the true thing in public. The Grove (monthly),
the talks (when booked), the book, and a gentle content rhythm (see #5) each carry the
same blossom, palette, and voice. Nothing new to invent — only consistent presence.
**Measure by the chair:** people in Kittitas County say "Brave Plum" and know what it
means without Johnny in the room.

### 2. The healing practice: 3–5 clients per week
**Today:** practice exists; volume unrecorded in the brain (⚠ current weekly average —
Johnny to state, so we know the size of the gap).
**The path:** the funnel is already built — discovery call → 90-minute sessions →
packages. What it needs is *flow into the top*: every Grove gathering, every talk, every
workshop ends with the same soft bridge (discovery call, once, no pressure). 3–5/week at
$228 ≈ **$2,700–5,700/month** from practice alone — a calm, sustainable core.
**First moves:** verify one real checkout end-to-end (long-standing item); Rachel and
Calendly flows confirmed; the site's Book page already leads with the gentle first step.

### 3. Online workshops — supporting healers, seekers, enlightened humans
**Today:** NEW TERRITORY — the site describes in-person workshops only. This is the
plan's biggest build.
**The path (crawl → walk → run):**
- *Crawl (this fall):* one workshop Johnny already teaches, recorded or delivered live
  over video — sold as a simple dated event through the existing Stripe + site Events
  pattern (events.json is already designed, unbuilt).
- *Walk (winter):* a small self-serve library page ("Workshops Online") — recorded
  sessions at a simple price; the gift/permission theme is the natural first title.
- *Run (spring 2027):* a recurring online offering with its own rhythm, feeding retreat
  waitlists.
**Johnny's decisions (⚠):** which workshop goes first · live vs recorded · platform
comfort (Zoom is enough to start).

### 4. Weekend retreats — established and well executed
**Today:** described beautifully on the site; no dated retreat has yet run through it
(⚠ confirm past-retreat history to state honestly).
**The path:** ONE retreat, executed with love, before July 2027 — that single truth does
more than any copy. Sequence: pick season & venue (Brave Plum Farm if ready, borrowed
venue if not) → cap at the site's honest 6–14 → deposits via existing Stripe day-rate
pattern → the Grove and workshop rooms are the natural first invitees.
**"Well executed" =** the neighborhood handles every logistic surface (page, payments,
waitlist, follow-up) so Johnny only holds the room.

### 5. A healthy social media presence (overwhelming no one)
**Today:** none (by design until now). The brand voice rules already forbid hype.
**The path — the "quiet garden" model:** ONE channel only (⚠ Johnny picks — where his
people actually are), a gentle fixed rhythm (e.g., 2 posts/week), and a sustainable
division of labor: Johnny speaks seeds (a line, a download, a Grove moment) → the crew
drafts in his voice → PR gate → posted. Nothing daily, nothing performative, no chasing
metrics — presence, not promotion. GoatCounter (cookie-less, wired, awaiting Johnny's
code) measures the site side without surveilling anyone.
**Guardrail:** if it ever feels like performing, we shrink it. The talks teach exactly
this; the channel must obey the teaching.

### 6. Organic growth — dollars finding Johnny on purpose
**Today:** already the operating truth (no ads, no funnels, no urgency anywhere).
**The path:** this is not a workstream — it is the *test* applied to every other goal:
would this move make a dollar chase us, or make us easier to find on purpose? The
findability work: the site's honest SEO (done), the Grove's hand-to-hand cards (printing),
talks that end with a single soft bridge (written), the book (below). Nothing else.

### 7. The website as the engine
**Today:** live, true, hierarchy-corrected, analytics-ready. Missing: real homepage stats
(⚠ the 500+/8+/40+ remain unconfirmed), events capability, online-workshop surface,
book page.
**The path (the engine grows a cylinder per quarter):** events/workshops (fall) →
online library (winter) → retreat page with deposits (winter/spring) → book page
(when the book is ready). Everything else — /admin, the ledger, the Grove — already runs.

### 8. The book: "We Endeavor Forth" — published and supporting Brave Plum
